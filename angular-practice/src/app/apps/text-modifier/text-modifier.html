Text Modifier

There are two facets to this: the client-side transformation and the server-side API integration.

The text transformation is handled clientside, and will process automatically as you type. This was to get a short handle on simple angular syntax and data binding.

The server-side API integration is handled by a simple .NET 8 Web API project. The text is sent to the API when you click the "Send to .NET API" button, and the response is displayed below the output panel.
